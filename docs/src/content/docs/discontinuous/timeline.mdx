`makeDiscontinuousLinearScale` compresses large gaps in a domain so
non-adjacent values don't waste visual space. Axis breaks are marked with a zigzag
rendered inline on the axis line, centered between adjacent continuous bins.
Ticks are sourced from continuous bins only — skip-bin indices are excluded so step
sizes stay uniform within each group.

Three common configurations are shown below: working-hours skip, weekday skip,
and a combined axis that compresses both overnight gaps and weekends simultaneously.
