Utility functions that spread geometry onto SVG element attributes without
requiring a d3 dependency. `applyRectangleAsProps` encodes x/y as a
CSS `translate()` transform and returns width/height as numbers.
`estimateSvgTextSize` gives a character-count pixel estimate for
text layout decisions (grey annotations below).
