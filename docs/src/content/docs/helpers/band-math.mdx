Low-level numeric primitives used by all scale factories.
`calculateLengthFromFixedBandsWithGaps` and `calculateLengthFromDynamicBands` size your SVG to fit exactly.

`calculateFitScaleFactor(contentLength, containerLength)` returns `containerLength / contentLength` — the uniform
factor that makes your content fill the available space. Use it directly, or pass `scaleTo` when constructing the
scale to get a pre-multiplied scale where all bandwidths, gaps, and positions are already scaled.
Read the factor back via `getScaleFactor()`.

The demo below shows a four-item fixed scale fitted to fill the selected container width — the pink tick at the
right edge marks where `getX1("D")` lands.
