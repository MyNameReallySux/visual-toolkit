All scale options that accept pixel values also accept CSS-unit strings
(`"24px"`, `"1.5rem"`, `"2em"`).
`stripPxFromPixels` and `stripSuffixFromCssNumber`
are the primitives that power this — export them to use the same parsing
in your own rendering code.
