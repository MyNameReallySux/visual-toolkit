`selectOrCreate(className, parent, tagName)` returns an existing child
element by CSS class or creates one if absent — making render functions idempotent.
Combined with a d3 data-join, re-running the render updates existing elements without
duplicating them. Click the button to re-render and watch the counter stay stable.
