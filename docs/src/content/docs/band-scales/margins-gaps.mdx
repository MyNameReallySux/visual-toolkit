`padStart` and `padEnd` add leading/trailing margins _inside_ the scale —
`getRange()` includes them, so the SVG width is always just
`scale.getRange()`. The colored anatomy below shows every zone at a glance.

Use the knobs to see how `getRange()` updates live as you change
`gap`, `padStart`, and `padEnd`.
