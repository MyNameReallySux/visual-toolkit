`makeEnumBandScale` is syntactic sugar over `makeDynamicBandScale` for string-literal keys.
`makeFixedEnumBandScale` filters disabled entries pre-build: the layout _collapses_ so enabled
items pack together. Use `doesKeyExist(key)` to guard reads on keys that may be disabled.
The two rows below show declared keys (reference) vs the collapsed actual layout.
