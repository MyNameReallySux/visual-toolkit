Multiple scales compose cleanly: shared rows come from a fixed band scale,
outer groups are grid columns with per-group widths, and each group nests its
own `makeEnumBandScale` for inner sections. Deriving every outer width from the
inner scale's `getRange()` means headers and columns can never drift apart —
the alignment holds by construction, not by hand-tuned constants.

Each group below independently controls its column widths while the row
positions are shared across all groups.
`calculateLengthFromFixedBandsWithGaps` derives the SVG height so nothing is
clipped.
