`makeDynamicBandScale` lets each item carry its own pixel width via `selectBandwidth`.
Here a 14-day calendar gives weekends a narrower column. Cell colors blend the column color
with the row color via `d3.interpolateRgb`. Drag the slider to shrink or expand weekends.
