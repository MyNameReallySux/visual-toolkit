`makeGrid` composes two axis specs (rows + columns) into a 2-D grid.
Each axis accepts a keys list, an entries list, or a pre-built scale.
Cells are addressed by literal key (`"row-1"`, `"col-0"`)
or by the numeric index embedded in the key suffix (`1`, `0`).

`getCellPosition` returns the top-left corner; `getCellRect`
returns full bounds (supports `rowSpan` / `colSpan`);
`getContentCellRect` returns the content-inset bounds.
Use `ExtractKeyFromEnumBandScale` to derive the key type at compile time.
