Pass `scaleTo: containerWidth` when building the scale and every bandwidth,
gap, and position is multiplied by a single uniform factor
(`containerWidth / naturalRange`) at construction time.
The visual fills its container exactly — widths and gaps scale together so proportions are preserved.
Read the factor back with `getScaleFactor()`.

The two containers below share the same scale parameters but receive different pixel widths
via the split slider. Drag any control to watch both containers re-fit live.
