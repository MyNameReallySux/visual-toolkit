`d3.scaleBand` divides a range into uniform bands by fraction — you have no
direct control over pixel widths. As soon as items differ in importance, you
need to manually derive the arithmetic.

`d3-band-scales` flips the model: you state the exact pixel bandwidth and gap
you want, and the library computes positions from them. Getters are named and
typed (`.getX0`, `.getBandwidth`, `.getGap`) rather than returning bare numbers
from a generic call. CSS-string values like `"24px"` are accepted everywhere a
number is.
