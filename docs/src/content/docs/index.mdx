`visual-toolkit` is a set of typed scale factories and SVG/D3 utilities built on
`d3-scale`. The `@visual-toolkit/d3-band-scales` package gives you explicit pixel
widths per item, configurable gaps, CSS-string options (`"24px"`), and a uniform
transform/fit API — all typed end-to-end in TypeScript.

## Install

```sh
npm install @visual-toolkit/d3-band-scales
npm install @visual-toolkit/d3-discontinuous-scale
npm install @visual-toolkit/d3-helpers
# peer deps (only if you also use d3-scale directly)
npm install d3-scale d3-selection
```
